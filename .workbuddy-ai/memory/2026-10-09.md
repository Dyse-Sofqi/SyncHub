## 轮次：环状虚影看不见 —— 换「在身上」的颜色变量

## 轮次：环常驻 + 悬停加保守的模糊扩散

用户反馈：「将虚影环常驻，悬停效果改为连带虚影的模糊扩散，扩散范围要保守，避免超出功能区」。

- **环搬到 base 规则**（常驻）：`box-shadow: 0 0 0 2px var(--obsync-avatar-ring)`；
  环色存进自定义属性 `--obsync-avatar-ring`（text-faint 60%）—— 悬停规则要**原样重复**
  这一层，因为 box-shadow 是简写、会整组替换（少了这层环就「消失」在悬停态）
- **悬停加柔光**：`0 0 6px 1px color-mix(in srgb, var(--text-faint) 50%, transparent)`
- **扩散范围是算出来的**：头像 28px 在 44px 功能区里居中，到 `.workspace-ribbon`
  的 `overflow: hidden` 裁剪边左右各 **8px**（4px 自动边距 + 4px ribbon 内边距）、
  上下约 12px。6px 模糊 + 1px 扩散 = 最大 7px，完整落在预算内一圈不裁
  （之前注释里写的「4px 余量」是错的 —— 那只是自动边距，漏加了 ribbon padding）
- 形态定格：**常驻环（2px 柔灰 60%）+ 悬停柔光（6px/1px，50%）+ 无 border + 光标默认**

`pnpm build:both` 两个库部署并核验（hash + 两条规则在位）。

1. **慢是主要代价，而且按提交数线性放大** —— 159 提交 9 分钟，1000 提交约 1 小时。

## 轮次：清理能力（体检 / 回收 / 深度清理）—— 已实现

用户选定 `filter-branch` 直接开工。新增 `historyObjects.ts`（体检的纯解析+汇总）、
`cleanup.ts`（耗时估算 / 路径归一 / shell 引号 / 备份引用命名）、`ui/CleanupReportModal.ts`
（一个弹窗三种状态：报告 → 确认 → 结果），以及 git 层与 service 层的对应方法。

### 六个坑（每一个都对应一次真实的失败，别改回去）

1. **重写用 `--branches --tags --remotes`，不是 `--all`**。`--all` 会把
   `refs/obsync-backup/*` 一起改写 → 备份**安静地**指向新历史，等于没有备份。
   在合成小仓上实测确认（分支/标签/远端引用全重写、备份 ref 原样保留）。
2. **备份引用在动手前建**（中途被强杀时 `previousHead` 已从所有引用上消失，事后补不出来）。
3. **超时按预计耗时放宽**：`GIT_BLOCK_TIMEOUT_MS` = 2 分钟会杀掉 9 分钟的重写，
   而那时它已经改了一半引用。给 `createGitInstance` 加了 `timeoutMs`，传「预计 × 3」。
4. **`.git-rewrite` 残留要先清**（否则 filter-branch 直接 `fatal: ... already exists` 退出，
   表现为「点了没反应」）。**两个候选位置**：`$GIT_DIR/.git-rewrite` 与库根
   （`GIT_DIR` 被显式设成仓库根时落这里，两种都实测遇到过）。
5. **锁内不能调 `writeGitignore`（死锁）** —— 它自己也进 `enqueue`。拆了无锁的
   `writeGitignoreNow`。踩到时三个用例直接 30 秒超时，症状是「点了深度清理界面卡住不动」。
6. **重写后必须顺手写忽略规则**（`ignorePaths(paths, [])`，**不摘索引**）——
   否则那些文件下次 `git add -A` 原样回来，用户看到「清完又长回来了」。

### 其他设计点

- 体检**按顶层目录**汇总（剔除的单位就是目录，每行正好是一个可执行动作）；
  只统计 blob；库根文件归 `.` 且**不提供勾选**（剔掉等于清空整个库）。
- 用 `--batch-all-objects` 而不是 stdin（simple-git 的 `raw()` 没有 stdin 通道）。
- 重写**空间不会立刻变小**（备份拉着旧对象），这是刻意的：先确认库能用，再丢退路。
  所以有独立的「丢弃备份并回收」（删备份 ref + `refs/original/*` + 过期 reflog + gc）。
- `--force` 而不是 `--force-with-lease`：重写时 `refs/remotes/*` 也改了，
  lease 比对的是新值，**永远不拒绝**（假保护）。理由写在 `forcePush` 注释里。
- 三个只读动作（体检 / 提交数 / 列备份）**不进 enqueue**；写动作全进。

## 轮次：用户问「为什么无论勾选什么，提示都是估计 9 分钟」
